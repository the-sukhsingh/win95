### 2. Start menu
The Start menu organized most system functionality into:

- **Programs** — installed applications
- **Documents** — recently opened documents
- **Settings**
  - Control Panel
  - Printers
  - Taskbar settings
- **Find**
  - Files or Folders
  - Computer
- **Help**
- **Run**
- **Shut Down**

It also supported nested/cascading program menus.
